# JavaScript穴埋めドリル

短いJavaScriptコードの空欄に入る答えを、4つの選択肢から選んで学べる初心者向けWebアプリです。

1回のセッションでは、選択したレベルからランダムに10問が出題されます。回答すると完成コードと解説が表示され、正解時にはネオン粒子や紙吹雪のエフェクトが発生します。

## 特徴

- 初心者向けのJavaScript穴埋め問題
- 5レベル、各100問（合計500問）
- 全レベルからバランスよく出題する「Level MIX」
- 1セッション10問を重複なしでランダム出題
- 問題順と選択肢を毎回シャッフル
- 回答直後に正解と解説を表示
- シンタックスハイライト付きコード表示
- 正解時のネオン粒子、衝撃波、紙吹雪エフェクト
- PC・スマートフォン対応
- キーボード操作対応
- ユーザー登録、Cookie、アクセス追跡なし

## 収録レベル

1. はじめの一歩：変数、値、文字列、基本演算
2. 条件分岐と繰り返し：比較、if文、ループ
3. 配列を使う：配列操作と代表的なメソッド
4. 関数とオブジェクト：関数、引数、戻り値、オブジェクト
5. DOMとイベント：HTML要素の操作とイベント処理
6. Level MIX：全5レベルから2問ずつ出題する総合チャレンジ

## 遊び方

1. レベルを選択します。
2. コードの空欄に入る選択肢を選びます。
3. 「回答する」を押して、正解と解説を確認します。
4. 10問回答するとセッション完了です。
5. 同じレベルへの再挑戦、またはレベル選択へ戻れます。

## ローカルで実行する

リポジトリをダウンロードまたはクローンし、`index.html`をブラウザで開いてください。ビルドやパッケージのインストールは不要です。

```text
javascript-drill/
├── index.html
├── style.css
├── app.js
├── 問題集.js
├── javascript-drill-design-spec.md
└── README.md
```

## GitHub Pagesで公開する

1. このプロジェクトをGitHubリポジトリのルートへ配置します。
2. GitHubのリポジトリ画面で「Settings」を開きます。
3. 左側のメニューから「Pages」を選択します。
4. 「Build and deployment」のSourceで「Deploy from a branch」を選びます。
5. 公開するブランチ（通常は`main`）と`/(root)`を選び、「Save」を押します。
6. デプロイ完了後、次の形式のURLでアクセスできます。

```text
https://<GitHubユーザー名>.github.io/<リポジトリ名>/
```

## 問題を追加・編集する

問題データは`問題集.js`で管理しています。画面へ表示するレベルは`window.LEVELS`から自動生成されるため、HTMLへレベルボタンを追加する必要はありません。`questions.js`は初期プロトタイプの参考ファイルであり、現在のアプリからは読み込まれません。

各レベルの`questions`配列には、100件の問題オブジェクトが直接登録されています。

```js
{
  "id": "array-push-cafe",
  "category": "配列",
  "prompt": "配列の末尾へ要素を追加してください。",
  "before": "const items = ['coffee'];\nitems.",
  "after": "(newItem);",
  "choices": ["push", "pop", "shift", "map"],
  "answer": "push",
  "explanation": "push()は配列の末尾へ要素を追加します。"
}
```

問題を編集するときは、次の点を守ってください。

- 問題IDを重複させない
- 選択肢を重複なしの4個にする
- `answer`を必ず`choices`のいずれかと一致させる
- 空欄より前を`before`、後ろを`after`へ記述する
- 問題文だけで正解を1つに決められる内容にする
- 問題コードは表示のみで、実際には実行されない

不正な問題データがある場合は、ブラウザの開発者コンソールへ具体的なエラーが表示されます。

## 使用技術

- HTML5
- CSS3
- Vanilla JavaScript
- [canvas-confetti](https://github.com/catdad/canvas-confetti)

`canvas-confetti`はjsDelivr CDNから読み込んでいます。CDNを読み込めない環境でも、CSSとJavaScriptで実装したネオン粒子エフェクトおよびドリル本体は動作します。

## アクセシビリティ

- 選択肢と操作ボタンには実際の`button`要素を使用しています。
- TabキーとEnterキーで回答できます。
- 正誤は色だけでなく、記号とテキストでも表示します。
- OSの「視差効果を減らす」設定が有効な場合、派手なアニメーションを停止します。

## プライバシー

外部通信は紙吹雪ライブラリの読み込みだけです。Cookie、LocalStorage、ユーザー登録、回答履歴の送信、アクセス追跡は行いません。
